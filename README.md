One funny new name for a planet of our solar system, plus the why, in a single line under 200 characters.

## Entry

> Venus is now Deadline: its day is longer than its year, so it is always late for its own birthday.

The joke: Venus's day (243 Earth days) is longer than its year (225 Earth days) — a trait no other planet shares — so a planet that can never be on time earns the name Deadline.

## Run

```sh
node main.ts
```

Writes the line to `/output/entry.txt` (override with `OUTPUT_PATH`). Node.js standard library only, no dependencies, no network.
